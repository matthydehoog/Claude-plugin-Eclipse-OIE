Lab 3: Creation and deploy of a simple channel

In this lab you build your first channel from scratch, deploy it and push an HL7 message through it. The channel does nothing clever yet: it receives a message and hands it on unchanged. That makes it the perfect place to learn how a message travels through OIE and where to find it afterwards.

Time: about 30 minutes

Purpose

In this lab you will:

  1. Create a simple channel with a Channel Reader as source and a Channel Writer as destination.
  2. Deploy the channel.
  3. Send a test HL7 message from the folder Mirth Training\Messages\HL7 and check the result in the Message Browser.

Before you start

  • You are logged in to the OIE Administrator.
  • You have the training files. The HL7 test messages are in Mirth Training\Messages\HL7.

Step 1: Create the channel

  1. Go to Channels and click New Channel.
  2. On the Summary tab:
    • Name: Lab 3 Simple Channel
    • Click Set Data Types and set the inbound and outbound data type of the source and the destination to HL7 v2.x.
    • Message Storage: Development. In this mode OIE keeps every version of the message, so you can see all of them in the Message Browser.
  3. On the Source tab, set the Connector Type to Channel Reader. A Channel Reader has no settings of its own: it accepts messages sent from another channel, or sent by hand with Send Message.
  4. On the Destinations tab, keep Destination 1 and set the Connector Type to Channel Writer:
    • Channel Id: None (the message is not forwarded to another channel yet)
    • Template: ${message.encodedData} (the message as it leaves the destination)
  5. Click Save Changes.

Step 2: Deploy the channel

  1. Click Deploy Channel (in the channel editor or in the Channels list).
  2. OIE opens the Dashboard automatically. Your channel is listed with status Started and all counters at 0.

Can't deploy? The channel may be disabled. In Channels, right-click the channel, choose Enable Channel, and deploy again.

Step 3: Send a test message

  1. Open the channel in the Message Browser (Dashboard: double-click the channel, or right-click > View Messages).
  2. Click Send Message in the task pane.
  3. Click Open Text File… and pick an HL7 file from Mirth Training\Messages\HL7, or open the file in a text editor and paste its contents.
  4. Click Process Message.

Step 4: Check the result

  1. In the Message Browser, click Refresh. A new message appears with status SENT for Destination 1.
  2. Select the message and look at the tabs at the bottom: Raw, Transformed, Encoded and Sent. Because the channel has no filter or transformer yet, the content is the same everywhere.
  3. Back on the Dashboard, the counters for the channel show Received 1 and Sent 1.
  4. Send two or three more files from the HL7 folder and watch the counters go up.

Done when…

  • The channel Lab 3 Simple Channel is deployed and Started.
  • At least one HL7 message has status SENT in the Message Browser.
  • You can explain what the Raw, Transformed and Encoded versions of a message are.

Stuck?

Download the solution channel below and import it via Channels > Import Channel. The solution is exported as disabled: enable it before you deploy. Compare it with your own channel to find the difference.

Optional: ask Claude

If the Claude Assistant is installed, open the Message Browser, select your test message and choose Ask Claude. Try:

  • "Explain this message: what type is it and which segments does it contain?"
  • "What does this channel do with a message?"

Notice that patient data in the PID segment is shown as ***: it is masked before it leaves the server.
